# PBOS: Pneumatic Beverage Opening System 🍾⚙️

> **Mechanical Design, Pneumatic Actuation, and Functional Prototype Validation**

PBOS is an automated, benchtop mechanical apparatus designed to standardize and streamline beverage bottle decapping through fluid power automation. The project integrates parametric CAD design, pneumatic circuit architecture, and physical prototyping.

## 🚀 Key System Features
- **Pneumatic Thrust Transmission:** Double-acting pneumatic cylinder operating at 4–6 bar to deliver reliable decapping force without bottle neck fracture.
- **Directional Valving & Control:** 5/2 single solenoid spring-return directional control valve manifold with throttle flow damping.
- **Rigid Frame Alignment:** Structural aluminum extrusions and toleranced plates ensuring strict concentricity between bottle axis and decapping hook.
- **Rapid Cycle Execution:** Consistent cycle completion under 3 seconds per container.
